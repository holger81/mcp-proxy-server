MCP Proxy

Config: /data/config/servers.json, domains: /data/config/domains.json. Each server belongs to a domain (unique id + label) for the public MCP surface: clients only see searchToolsForDomain (query or explicit listAll, paginated), searchTool, and callTool — not every upstream tool at once. Package stdio uses PyPI/npm under /data/venvs or /data/npm; manual stdio uses commands already on PATH.

            mail-mcp — environment variables (reference)
            

              Use segment names like DEFAULT, WORK, GMAIL in place of
              DEFAULT below. Multi-account = multiple MAIL_*__… groups.
              Full upstream docs.
              There is no supported env var to skip TLS certificate verification.

        roots). Prompts → prompts/list (templates). Capabilities → MCP
